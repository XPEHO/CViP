# Politique de sécurité

CViP gère des CV de consultants, des données personnelles (RGPD). Le dépôt est public : aucun secret ni aucune donnée réelle de consultant ou de client ne doit y figurer.

## Signaler une faille

Si vous pensez avoir trouvé une faille de sécurité (dans le code, la documentation ou l'infrastructure) :

- **Ne l'ouvrez pas en issue publique.**
- Utilisez le signalement privé de GitHub (onglet _Security_ > _Report a vulnerability_) lorsqu'il est disponible sur ce dépôt.
- Sinon, contactez les propriétaires du dépôt (voir `.github/CODEOWNERS`) via leur profil GitHub.

Indiquez la nature du problème, comment le reproduire et son impact potentiel. Si vous découvrez un secret ou une donnée personnelle réelle dans le dépôt, signalez-le de la même façon.
